CodeMie GEO Enterprise Competitor Diagnostic
Analyze and benchmark your website’s Generative Engine Optimization (GEO) and technical SEO readiness against up to 4 competitors.
This project provides executive-grade, actionable dashboards for RAG/LLM and enterprise SEO architecture.


Features
Multi-site benchmarking: Main site + up to 4 competitors
Enterprise heuristics: Checks for SSR content, structure, discoverability, AI accessibility, etc.
Unique independent scoring: Each site is fetched and scored separately
Radar/spider chart: Fast visual comparison
Scores table: All criteria for all sites, side-by-side
Business value / technical effort matrix for all fixes
Full phase-based action roadmap and rich, business-friendly explanations

Usage
Install required packages

Download
pip install streamlit requests beautifulsoup4 plotly
Run the app

Download
streamlit run codemie_geo_assistant.py
In your browser:

Enter up to 5 URLs (your site and competitors)

Click to run the benchmark

Review the table, spider chart, and detailed dashboards for recommendations

Files
codemie_geo_assistant.py – Streamlit app (main logic, UI, and diagnostics)
code.py – Core enterprise heuristics (merged into app)
activia.html – Sample of executive-level HTML report style

Why Use?
See exactly where your architecture stands vs. direct competitors
Get a prioritized, actionable technical/business improvement roadmap
